# DownFall-rs
DownFall-rs is a rust-y, gtk-layer-shell application that moves text items of your choice across the screen  

https://github.com/user-attachments/assets/33b3254a-5e19-4356-bccc-020c9d766fd7

DownFall-rs is a re-implementation of the [DownFall](https://github.com/torculus/DownFall) GNOME shell extension, which was inspired by projects like [Xsnow](https://sourceforge.net/projects/xsnow/), [gsnow](https://extensions.gnome.org/extension/1156/gsnow/), and [Let it snow](https://bitbucket.org/matban/let-it-snow/src/master/), but with support for arbitrary text or Unicode emojis

## Configuration
Text items can fall in eight directions on either the primary or current monitor:  
- Down (↓)
- Up (↑)
- Right (→)
- Left (←)
- Up-right (↗)
- Up-left (↖)
- Down-right (↘)
- Down-left (↙)

Additional configuration options (will!) include color, font, size, fall speed/time, rotation, and drift
